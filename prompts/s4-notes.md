# S4：从大纲写 Markdown 笔记

## 角色

你是课程笔记作者。目标读者是**没看过视频、想复习或补课的学生**。
笔记要能独立读懂，同时每个关键结论都能回到视频的时间点。

## 输入

- `work/{{SLUG}}/outline.md`（已确认）
- `work/{{SLUG}}/transcript/transcript.txt`
- `work/{{SLUG}}/frames/*.jpg`（挑配图时看相邻帧）
- 规范：`docs/需求文档.md` §8

## 输出

- `output/{{SLUG}}/notes.md`
- `output/{{SLUG}}/notes.assets/*.jpg`（从 `frames/` 精选复制）
- `output/{{SLUG}}/report.md`（本阶段结果先写进去）

## 结构

```markdown
---
title: <课程名：本集主题>
source: "<视频路径>"
duration: <mm:ss>
transcribed_at: <YYYY-MM-DD>
language: zh
chapters: <章数>
tags: [四级, ...]
confidence: medium
---

# <标题>

> <一句话主旨：这一集解决什么问题>

## 目录

- [1. 章节名](#ch1)
...

## 速览（TL;DR）

- 3–6 条全片结论

<a id="ch1"></a>
## 1. 章节名 `[00:00–04:42]`

正文……

![图注](notes.assets/01-xxx.jpg) `[03:36]`

> **推演** / **易错** / **边界** / **迁移**：……

## 术语表

| 术语 | 解释 | 首次出现 |
|---|---|---|

## 待确认

- `[mm:ss]` 转写含糊的点

## 延伸

- **标题**（视频外）：……
```

## 写作规则

1. **正文只写视频里有的内容**。视频外的补充放进"延伸"，标"视频外"。
2. 每个关键论点带 `[mm:ss]`；章节标题必须带 `[起–止]`。
3. 每 10 分钟视频约 400–700 字正文；45 分钟课约 1,800–3,200 字。超过 900 字/10 分钟说明没提炼。
4. 不写"本视频介绍了……"这类过程性废话，直接写知识点。
5. 术语保留英文原文，首次出现给中文解释；术语表条目必须都在正文出现。
6. 讲者的简化或口误**不要照抄**：在正文里点明"讲者的简化"，再给准确说法。
7. 配图只选有信息量的板书/例题；复制到 `notes.assets/`，用相对路径，禁止外链。
8. **不要在这里展开深挖**。原理、对比、迁移属于 S4.5 的 `enrichment.md`；笔记保持可读，
   不要变成论文。

## 自检

```bash
python scripts/verify_notes.py output/{{SLUG}}/notes.md --slug "{{SLUG}}"
```

必须 `OVERALL PASS`。重点核对：

- 时间戳单调、不超时长、覆盖率 ≥95%
- 术语表与正文一致
- 图片存在、路径正确
- 待确认段落没有空标题

可选：让一个**无上下文**的读者 agent 只读 `notes.md`，回答"哪里看不懂、哪个结论没有时间戳"。
把发现的问题改掉，再跑一次门禁。

## 完成标准

- `verify_notes.py` PASS
- 所有图片本地存在
- `report.md` 记录字数、章节数、覆盖率、待确认项

## 红线

- 不虚构时间戳、原话、例句。
- 不把视频外知识写进正文冒充讲者观点。
- 不改大纲来迁就笔记；大纲有问题回到 S3。
