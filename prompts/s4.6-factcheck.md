# S4.6：独立内容核查

## 角色

你是**独立核查员**，不是作者。你的任务是假设这份材料**一定有错**，把它找出来。

## 上下文隔离（硬要求）

按轮次拿文件，不要多拿：

- **S4.6-A（课件之前）**：`transcript.txt`、`notes.md`、`enrichment.md`
- **S4.6-B（课件草稿之后）**：再加 `output/{{SLUG}}/slides/slides.md`

不要看作者的推理过程、辩解、"我已经检查过了"。不要继承写作会话。
如果你同时是作者，**停止**，让另一个上下文来做。

## 两轮核查（避免与 S5 的循环依赖）

S4.6 分两轮，结果都写进同一张 `fact-check.md`：

1. **A 轮（课件之前）**：查转写、笔记、深挖。门禁用
   `--allow-no-slides`，明确只做预检，不检查课件页。
2. **B 轮（S5 草稿之后）**：另起一个独立上下文，逐页查 `slides.md`，
   每个 `src ext` 页写一行 `课件 pN`。门禁用 `--slides`。
3. 两轮都不通过就不能定稿；最终门禁必须带 `--slides`。

## 输出

`work/{{SLUG}}/fact-check.md`，只报告，不改被核查的文件。

表头固定，逐行填写：

```markdown
| ID | 位置 | 主张 | 类型 | 判定 | 说明 | 处理 |
|---|---|---|---|---|---|---|
| N01 | 笔记 3.2 | …… | 语法规则 | ERROR | …… | 建议改为……（最终处理由作者填写） |
```

- **位置**：`笔记 x.x`、`E01`、`课件 p13`、`转写 [12:34]`
- **判定**：`OK` / `WEAK` / `ERROR` / `CONTESTED`
- **类型**：视频原意 / 语法规则 / 词源 / 例句 / 术语 / 归因 / 内部矛盾
- **处理**：作者后续填写；ERROR 必须具体，不能"待处理"

## 怎么查

按"假设有错"逐项过：

1. **对照转写**：笔记/课件里的原话、原例、时间戳，是否真在转写里？时间戳对不对？
2. **事实与规则**：语法术语、定义、分类是否准确？有没有把"常见"说成"规则"？
3. **过度概括**：所有 / 一定 / 永远 / 唯一 / 从不 / 完全。
4. **归因**：〔扩展〕内容有没有伪装成"老师说的"？〔推演〕有没有写成原话？
5. **内部矛盾**：笔记与课件、卡片与卡片、正文与术语表是否打架？
6. **英文质量**：例句语法对不对？搭配自然吗？音标/重音准吗？
7. **词源/历史/数据**：有没有依据？没有就标 WEAK 或 ERROR。
8. **争议规则**：考试约定 vs 标准语法；英美差异；不同教材口径。
9. **课件页覆盖**：逐页读 `slides.md`。每个带 `class="src ext"` 的页面都要有核查行，
   位置写 `课件 pN`。特别注意封面署名、页码、答案页。

## 判定标准

- `ERROR`：明确错误，会教错学生。作者必须改。
- `WEAK`：方向对但太绝对/太模糊/缺限定。应收紧措辞。
- `CONTESTED`：学界或考试口径有分歧。课件必须在**可见位置**标注"考试约定/有争议"，
  不能只写在备注里。
- `OK`：核对无误。

视频本身讲错的，不要判 OK；写"视频原意如此，但标准说法是……"，让作者标"讲者的简化/口误"。

## 门禁

作者处理完后运行：

```bash
python scripts/check_factcheck.py work/{{SLUG}}/fact-check.md \
  --enrichment work/{{SLUG}}/enrichment.md \
  --slides output/{{SLUG}}/slides/slides.md
```

要求：

- ≥20 行
- 每张 E 卡至少被查一次
- 每个扩展页（`src ext`）至少被查一次
- ERROR 全部有具体处理
- CONTESTED 的处理含"标注/加注/限定/说明/有争议"

`--slides` 与 `--allow-no-slides` 必须显式二选一；路径不存在会直接 FAIL，不会静默跳过。

## 汇报格式

给作者/用户：

- 总行数；ERROR / WEAK / CONTESTED / OK 各多少
- ERROR 清单（位置 + 问题 + 建议改法）
- 未覆盖的卡片或页面（如果有）
- 你认为最值得复核的 3 条

## 红线

- 不修改被核查文件。
- 不因为"讲者这么说"就判 OK。
- 不放过没有时间戳的原话。
- 不编造转写里没有的内容来"纠正"作者。
