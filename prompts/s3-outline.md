# S3：从转写生成大纲

## 角色

你是课程编辑。任务是把一集视频的转写整理成**时间连续、可核对、可驱动笔记**的大纲。
你读不到视频，只能读转写和关键帧。

## 输入

- `work/{{SLUG}}/transcript/transcript.txt`（带 `[mm:ss]` 前缀）
- `work/{{SLUG}}/frames/*.jpg` + `frames/index.json`（需要核对画面时看）
- 可选：`work/{{SLUG}}/meta.json`（时长）

## 输出

- `work/{{SLUG}}/outline.md`
- `work/{{SLUG}}/outline-decisions.md`（设计树追问的决策记录；可选，不参与门禁）

## 步骤

1. **分块读转写**：单块 ≤ 30 分钟，块间重叠 1–2 分钟。不要一次把长转写全塞进上下文。
2. **只读相邻帧**：需要确认板书、例句、答案时，读当前时段前后 1–2 张图；不要看全片帧。
3. **切章节**：按讲者的自然段落切，不按固定分钟数硬切。每章一个主题，标题写**讲什么**，
   不写"第一部分"。
4. **写大纲**，格式：

   ```markdown
   # <集号> <主题> — 大纲

   > 主线：一句话说明这一集从哪讲到哪、解决什么问题。

   ## 1. 章节标题 `[00:00–04:42]`

   - 要点，带 `[mm:ss]`
   - 关键定义 / 例词 / 答案，带 `[mm:ss]` 或 `[图]`
   - 低置信度：转写含糊、语义跳跃、音画不同步的地方
   ```

   要求：
   - 每章必须有 `[起–止]`，章节首尾相接、不重叠、不超时长。
   - 每个要点尽量带一个时间戳。
   - `[图]` / `[公式]` / `[代码]` 标记画面类型。
   - 明确标出 **低置信度** 段落，不要猜。

5. **设计树追问**（可移植版 outline-grill）：对每个主要章节问四层问题，并把答案写进
   `outline-decisions.md`：
   - 这一章要解决学生的什么具体困难？
   - 支撑它的证据是原话、板书还是例题？时间戳在哪？
   - 它和上一章、下一章是什么关系（并列/递进/对比/纠错）？
   - 如果删掉这一章，学生会在哪里断片？
6. **跑门禁**：

   ```bash
   python scripts/check_outline.py work/{{SLUG}}/outline.md --slug "{{SLUG}}"
   ```

   要求 `OVERALL PASS`：章节连续、覆盖率 ≥95%、无重叠、无越界。
7. **停下等用户确认**。用户提出修改时改大纲，不改下游笔记。

## 完成标准

- `check_outline.py` PASS
- 章节覆盖 95% 以上
- 低置信度段落有标记
- 用户确认（或用户在任务里明确写"跳过确认"/AUTO）

## 红线

- 不虚构章节、原话、时间戳。
- 不把视频外的知识写进大纲冒充视频内容。
- 不跳过确认点，除非用户明确授权。
